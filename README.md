# Stemmero

## Formål

Et lille Windows-program, der advarer med et gult, orange eller rødt banner og en tone, når du taler for højt i headsettet under spil. Alle må hente, bruge og ændre programmet under MIT-licensen. Færdige installationsfiler skal kunne hentes fra GitHub Releases.

## Åbne spørgsmål

Den første udgave skal afprøves med et fysisk headset og et spil på Windows.
